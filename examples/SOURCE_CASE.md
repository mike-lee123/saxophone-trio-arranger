# 黃昏的故鄉圖片案例

原圖為使用者提供的 875×1181 JPEG，來源 SHA-256 見 source/manifest.json。

huanghun.draft.json 現包含 30 個印刷小節的 AI 視讀初校候選，所有事件 uncertain=true，人工確認 0/30。不是 OpenAI API 實際辨識回應，也不是已確認的正式轉譜。

逐小節初校紀錄.md 與逐小節初校與待確認紀錄.pdf 列出原圖裁切、三連音、八度點、附點、和弦與跳轉等檢查重點。第19小節第3拍起與第20小節 N.C. 已明確寫入模型。反覆／Segno／Coda／Fine 路線與部分小字裝飾音仍待使用者確認。

演歌取樣試聽.mp3 是整合版錄音取樣引擎產生的 23 秒草稿示範，不代表人工聽審。完整來源與波形檢查見整合試奏驗證.json。

synthetic-output.zip 是獨立合成旋律的已確認測試輸出，不是本歌曲。測試程式不會替這首歌曲填寫人工確認。
